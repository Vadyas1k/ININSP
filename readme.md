# 📝 Web-Notepad (Проект на этапе проектирования)

> ⚠️ Данный репозиторий находится на стадии старта. README оформлен как Pull Request для обсуждения идеи, архитектуры и плана работ. Все правки будут вноситься после получения фидбека.

---

## 🎯 Идея и цель проекта
Создать веб-приложение «блокнот», которое автоматически сохраняет введённый пользователем текст без необходимости регистрации или ручного нажатия кнопки «Сохранить». 

**Главная цель:** обеспечить мгновенный доступ к заметкам, устойчивость к перезагрузке страницы и закрытию вкладки, а также продемонстрировать работу с серверным хранением данных и базовыми принципами веб-разработки на Python в рамках учебного Git-потока.

---

## 📋 Планируемый функционал
| Приоритет | Функция | Описание |
|-----------|---------|----------|
| 🔴 High | Автосохранение ввода | Отправка текста на сервер в реальном времени с debounce-задержкой (500–800 мс) |
| 🔴 High | Восстановление сессии | Автоматическая подгрузка последней версии при повторном открытии по уникальному ID сессии |
| 🟡 Medium | Очистка заметок | Кнопка сброса с подтверждением действия, обрабатываемая на сервере |
| 🟡 Medium | Адаптивная вёрстка | Корректное отображение интерфейса на мобильных устройствах и десктопах |
| 🟢 Low | Экспорт текста | Возможность скачать содержимое в `.txt` или `.md` через серверный endpoint |
| 🟢 Low | Счётчик символов | Отображение статистики ввода на клиенте без лишних запросов |

## 🏗 Предполагаемая архитектура и стек
Проект планируется реализовать как **лёгкое веб-приложение на Python**, где бэкенд отвечает за маршрутизацию, хранение данных и API, а фронтенд представлен минимальными статическими файлами для отображения и отправки запросов.

### 🛠 Технологический стек
- **Backend:** `Python 3.10+` + `Flask` (роутинг, обработка POST/GET запросов, управление сессиями)
- **Хранение данных:** `SQLite` (через стандартный модуль `sqlite3`) для надёжного хранения заметок, привязанных к сессии пользователя
- **Frontend:** `HTML5` + `CSS3` + минимальный `Vanilla JS (Fetch API)` только для асинхронной отправки/получения данных без перезагрузки страницы
- **Инструменты:** `pip`, `python-dotenv` (для конфигов), `Git` + `GitHub`
- **Деплой:** `Render` / `PythonAnywhere` / `Railway` (поддержка WSGI-приложений на Python)

### 📁 Структура проекта (планируемая)
```text
web-notepad/
├── app.py                # Точка входа Flask, маршруты, логика сохранения
├── models.py             # Работа с БД (создание таблиц, CRUD-операции)
├── templates/
│   └── index.html        # HTML-разметка с подключением статики
├── static/
│   ├── style.css         # Стили и тема
│   └── script.js         # Fetch-запросы, debounce, обработка UI
├── requirements.txt      # Зависимости Python
├── .env                  # Конфигурация (секреты, режим отладки)
└── README.md             # Документация и планы
```

### 🔌 Схема взаимодействия
```text
[Browser] → (POST /save с debounce) → [Flask: app.py] → [models.py] → (SQLite INSERT/UPDATE)
     ↑                                                              ↓
     └────── (GET /load с session_id) ←──── [Flask] ← (SQLite SELECT) ←┘
```
